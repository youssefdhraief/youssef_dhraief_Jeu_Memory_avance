👤 À propos de moi

🎓 Formation

Étudiant en Le Cycle Préparatoire Intégré à la Faculté des sciences de Tunis (FST), passionné par le développement web et les projets interactifs.

💻 Compétences techniques

Je travaille principalement avec :
HTML5 • CSS3 • JavaScript (ES6+) • Responsive Design • Animations CSS • Manipulation du DOM • Gestion d'événements • LocalStorage • Git

🧠 Ce projet

Ce jeu de mémoire a été réalisé dans le cadre d'un projet évalué.

L'objectif était de créer un jeu interactif et agréable, tout en mettant en pratique mes compétences en développement front-end.

Le projet propose :
          un mode solo
          un mode 1v1 local
          un mode contre un bot simple

🚀 Technologies utilisées

Le projet est entièrement développé avec :

HTML5 • CSS3 • JavaScript pur

Sans utilisation de bibliothèques externes, ce qui m'a permis de mieux comprendre les bases du développement web et la gestion des interactions utilisateur.

🎮 Comment Jouer

🧍 Solo

Trouve les paires dans le temps imparti selon la difficulté.

⚔️ Multijoueur / Bot

Meilleur score sur 3 manches. La difficulté augmente à chaque tour.

🃏 Cartes spéciales

👁️ AkuAku (10 pts)

Révèle une carte sans perdre ton tour

🔄 Permutation (5 pts)

Échange la position de 2 cartes

📌 Règles

Score : chaque match réussi double le score (base 1)

Achat : utilise ton score pour acheter des cartes

Rareté : plus rare = plus cher

2 joueurs : meilleur score gagne si temps écoulé
