👤 À propos de moi

🎓 Formation

Étudiant en Le Cycle Préparatoire Intégré à la Faculté des sciences de Tunis (FST), passionné par le développement web et les projets interactifs.

💻 Compétences techniques

Je travaille principalement avec :
HTML5 • CSS3 • JavaScript (ES6+) • Responsive Design • Animations CSS • Manipulation du DOM • Gestion d'événements • LocalStorage • Git

🧠 Ce projet

Ce jeu de mémoire a été réalisé dans le cadre d'un projet évalué.

L'objectif était de créer un jeu interactif et agréable, tout en mettant en pratique mes compétences en développement front-end.

🚀 Technologies utilisées

HTML5 • CSS3 • JavaScript pur — sans bibliothèques externes.

🎮 Comment Jouer

🧍 Solo

Trouve toutes les paires dans le temps le plus courte.

🤖 vs Bot

Affronte le bot. Meilleur score à la fin gagne. Si tu trouves une paire, tu rejoues !

⚔️ 1 vs 1

Deux joueurs, même écran. Meilleur score gagne. Paire trouvée = rejouer !

🃏 Cartes spéciales
